Vendored unchanged from https://github.com/Jakeschincariol/replica-skill (MIT, see `LICENSE`),
commit 77c9436, version 1.0.0. The eleven `replica-*` skill folders sit next to this one in
`.claude/skills/` so they load as plain `/replica-recon`, `/replica-build` and so on.
To update, copy the `replica-*` folders and `LICENSE` from a newer commit and change the commit line here.

These are Claude Code skills for cloning the features of an app (recon, architecture, design, build, test, deploy).
They are for working on this repo's tooling; Shadow's runtime does not load them.
