# Shadow adapter: theme factory

Use this skill for requested colors, themes, visual identity, and dashboard styling. Follow the owner's stated direction; if no palette is specified, choose a suitable palette and make the result reviewable. Do not pause to request a theme choice when the request already authorizes a design change.

The upstream PDF showcase is not installed in Shadow. Use the text palettes in `themes/` as references. `midnight-galaxy.md` and `tech-innovation.md` are useful starting points for Shadow's dark console, but preserve contrast, keyboard focus, responsive layout, and the existing product brand. Do not apply Anthropic branding to Shadow.

In Development Studio, propose or produce changes only in the supplied source files. No browser, shell, package installation, or deploy tool is available to that model; never claim those steps were run. A proposed patch is not live until applied and deployed separately.
