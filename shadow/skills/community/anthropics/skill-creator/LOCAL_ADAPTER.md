# Shadow adapter

Use this skill when creating or improving a reusable Shadow prompt/skill. Write a focused Markdown file under `shadow/skills/`, state when it should activate, give concrete instructions and a few short examples, and keep it compatible with the existing Uzbek style, chat isolation, honesty, and privacy rules. Register it in `shadow/assistant.py` only when runtime loading requires that. Do not claim a skill was evaluated or improved by benchmarks unless those runs actually happened; do not block useful work on optional evaluations.
