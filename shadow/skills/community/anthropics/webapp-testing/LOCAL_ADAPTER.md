# Shadow adapter

Use this skill for browser/UI verification requests. This service's Development Studio can inspect and modify source and prepare a patch, but it does not have a browser or command execution tool. Use the skill to design a concrete manual or automated verification plan and to write focused checks when requested. Never say Playwright, a browser, or tests ran unless a connected tool actually ran them.
